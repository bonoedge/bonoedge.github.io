Privacy Policy

Effective date: 2026-10-04

bonoedge Content Tools ("the app") is a private, internal tool operated by bonoedge. It is used only to manage YouTube channels that bonoedge itself owns. It is not offered to the public, and no other person's account is connected to it.

1. What Google user data the app accesses

When a channel owner grants consent through Google's OAuth screen, the app may use these scopes:

  • yt-analytics.readonly — to read performance reports (views, average view duration, average view percentage, subscribers gained and lost) for the owner's own channel.
  • youtube.upload — to upload videos that bonoedge produced to the owner's own channel, as private or scheduled videos.
  • youtube.readonly — to confirm which channel a token belongs to and to read back the status of uploaded videos.

2. How the data is used

The data is used only to publish our own videos and to measure how they perform. The app does not use it for advertising. It does not sell Google user data. The app does not use it to build profiles of viewers. Reports are aggregate channel and video statistics provided by YouTube; they do not identify individual viewers.

3. Storage and retention

OAuth tokens are stored only on the operator's own computer, in files excluded from version control. Aggregate report numbers are stored in operator-controlled project files for as long as they are useful for measurement. Selected aggregate reports are also stored in the operator's private GitHub project for collaboration. These report files are distinct from OAuth credentials.

4. Sharing

The operator uses GitHub for private project storage and authorized AI assistance services to analyze selected aggregate channel reports. These services receive only the report information needed for that work, not OAuth tokens. Google user data is not sold or shared for advertising. The app does not use Google user data to train general-purpose AI models. Disclosure may also occur where required by law.

5. Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

6. Revoking access and deletion

Access can be revoked at any time at Google Account → Third-party access. After revocation the app can no longer read or upload anything, and the operator deletes the stored token files. To request deletion of stored report data, use the contact link below. Do not post OAuth tokens, credentials, or private report data in a public issue.

7. Changes

If this policy changes, the new version will be posted on this page with a new effective date.
